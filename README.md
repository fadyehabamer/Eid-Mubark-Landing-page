# Eid Mubark 2021
> Landing page made with :
>
> - HTML
> - CSS
> - Lottie-Files 
>   - Animated SVGs

A one-page Arabic (right-to-left) Eid greeting landing page with an animated [Lottie](https://lottiefiles.com/) illustration.

**Live demo:** https://fadyehabamer.github.io/Eid-Mubark-Landing-page/

## Run locally

No build step. Open `index.html` in a browser (an internet connection is needed for the Google Font, Font Awesome, the Lottie player and the animation JSON), or serve the folder:

```bash
python3 -m http.server 8000
```

The animation respects the operating system's *reduce motion* setting.
